# 大法师 · 互刷研究所

海克斯大乱斗“大法师”技能冷却研究工具。搜索英雄、查看中文技能与图标、比较所有技能对，计算无限互刷所需的最低技能急速及所有并列最优加点。

**非官方、理论工具，不操作游戏客户端。当前仅本地实现，未发布公网网站。**

## 本地使用

需要 Node.js 22 或以上版本。网页运行和构建没有第三方依赖。

```bash
npm run dev
# 浏览器打开终端输出的本地地址，默认端口 5173

npm test
npm run build
npm run preview -- --port 5180
```

不要直接双击 `index.html`，浏览器可能阻止加载本地 JSON。

## 功能

- 173 个英雄，按中文名、称号或英文 ID 搜索。
- 本地英雄及技能图标、中文基础说明、逐等级 CD。
- Q/W/E/R 全技能对比较；全部并列最优加点，不擅自偏好高等级组合。
- 自选两个技能等级，即时查看门槛与双向返还解释。
- 显示理论急速门槛与向上取整的整数急速建议。
- 充能近似标注；特殊交互、缺失数据显式排除。
- 桌面和手机布局，键盘搜索快捷键 `/`。
- 固定版本快照，无自动更新、账号、追踪或出装推荐。

## 模型

根据需求方实测，只交替施放 A/B 时，返还一定命中另一技能。返还量为施放技能当前等级、急速缩减前基础 CD 的 30%。

```text
实际 CD = 基础 CD / (1 + H/100)
H_min = max(0, 100 × max(C_A/(0.3 × C_B) − 1,
                         C_B/(0.3 × C_A) − 1))
```

模型要求单次返还足以清空对方完整实际 CD，忽略施法时间、自然冷却、目标要求与资源消耗。包含 R，但不计算独立大招急速或其他特殊急速来源。基础 CD 相同时门槛为 `233⅓`，整数急速需至少 `234`。

## 数据与准确性边界

- 版本锁定为 **16.21.1**。普通 CD、中文说明、图标重新采集自 Riot Data Dragon。
- 充能技能暂用用户提供的同版本旧快照中的单层回复时间；存于 `data/charge-source-16.21.1.json`，**尚未独立重新核验**。
- 旧数据中一些内部 ammo 字段并非玩家可储存充能，已针对已识别槽位排除该误判。
- 部分形态、重施放、条件重置和属性影响技能暂不参与排名；人工例外清单不保证穷尽所有情况。
- Data Dragon 基础技能数据不保证覆盖海克斯大乱斗的全部模式修正。**数据真实来源不等于所有模式交互已验证。**
- 技能说明为基础描述，不一定包含完整动态伤害数值；本项目核心关注技能冷却。

### 手动更新同版本快照

```bash
python3 scripts/fetch_data.py
npm test
npm run build
```

采集器使用 `.cache/16.21.1/` 原始 JSON 缓存；没有定时任务，不追踪 `latest`。更换版本时需显式修改采集版本，并重新核验充能来源与例外，不能混用版本。`public/data/champions.json` 和 `public/assets/` 必须纳入版本管理，保证克隆后无需联网抓取即可构建。

## 浏览器测试

Playwright 仅作为开发依赖，不进入网站：

```bash
npm ci
npx playwright install chromium
npm run test:e2e
```

也可以复用已有 Chrome，设置 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 为本机可执行文件路径。测试自动构建，并启动独立的 5180 端口预览服务。

测试覆盖搜索、筛选、技能说明、并列加点、手动等级调整、键盘操作、加载失败、静态子路径与 320–1440 像素布局；截图位于忽略提交的 `artifacts/`。

## 后续 GitHub Pages 部署

这里只提供配置，不会替你创建仓库或公开发布。

1. 将本目录作为独立 Git 仓库上传到你之后创建的公开 GitHub 仓库。
2. 在仓库 Settings → Pages 中将 Source 设为 **GitHub Actions**。
3. 在 Actions 中手动运行 **Deploy Archmage Lab**。
4. 成功后通过部署结果给出的地址访问，手机和电脑使用同一地址。

工作流只由手动按钮触发，不定时更新数据，也不在每次推送时自动发布。`dist/` 是唯一发布目录；ZIP、旧程序、证书、原始缓存和测试截图不会进入站点。

项目使用相对路径，兼容 GitHub Pages 的仓库子路径。正式公开前仍需核验并落实 Riot 的素材使用、产品注册及非官方声明等适用政策。当前未替用户选择代码开源许可证；游戏素材不属于本项目代码的授权范围。
