# R 五秒宽限规则（2026-10-31）

本规则覆盖文档 07 中“所有 >500 门槛一律隐藏”和船长 ER 隐藏的结论，不改动固定技能数据。

## 验收规则

1. 无缝循环门槛 ≤500 急速的结果照旧显示与优化。
2. 若某等级搭配无法在 500 急速无缝循环，且被刷新的技能为普通大招 R，则在固定 500 急速下检查例外。
3. 连续施放另一技能（充能技能最多为该等级容量）后，R 剩余冷却必须在 `(0,5]` 秒。
4. R 的返还必须足以补回本轮消耗的另一技能的全部冷却/充能，不借初始存量，不依赖等待期间的自然充能来放宽此条件。
5. 非 R 的剩余冷却不允许五秒宽限；双充能对仍不计算，充能 R 不视为普通大招 R。
6. 标明“500 急速下近似循环，R 仍需等待 X 秒”，不写作无缝互刷，也不把固定 500 标为最低无缝门槛。

## 计算与并列

H=500 时实际 CD 为基础 CD 除以 6。对单层回复时间为 C、容量为 N 的充能技能，枚举 n=1…N：

- R 剩余：`max(0, R/6 - n×0.3×C)`；需 `0 < 剩余 ≤ 5`。
- 充能补回：`n×C/6 ≤ 0.3×R`。

普通非 R 技能按 N=1 处理。所有边界用内部数值判断，不先四舍五入。

优先展示无缝结果，并保持“最低技能急速”的原优化目标；宽限结果单独标注。在只能选择宽限的技能对/英雄中，固定 500 急速，以 R 剩余等待最短选推荐加点；相同等待的等级搭配与施放次数完整保留。混合技能对的手动等级选择也能查看宽限搭配，但不会与无缝最优混为并列。

## 船长回归样例

E5 单层基础回复 13 秒、最多 5 层；R3 基础 CD 120 秒。

- 500 急速：R 实际 CD 20 秒。
- E 连放 5 次：累计返还 `5×13×30%=19.5` 秒，R 剩 **0.5 秒**。
- R 返还 36 秒；5 层 E 回复总计 `5×13/6≈10.833333` 秒，足够补回，下一轮可重复。
- 因此 ER 重新显示，推荐 **E5/R3**，但明确为有 0.5 秒等待的近似循环。
