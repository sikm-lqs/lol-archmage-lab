# 首版实现规格

用户已确认需求与视觉委托，并授权开始。仅本地实现，不创建远端或公开发布。

## 目标和边界

实现中文响应式静态站：全英雄名字搜索、技能图标与说明、各技能对最低急速及所有并列加点、双向计算解释。包含 R，不限定英雄等级，不推荐出装，不自动更新。

固定 16.21.1 数据快照。Data Dragon 中文单英雄数据本轮已确认可访问。普通 CD 重新采集；充能时间与旧快照比对，来源与近似明确记录。变形、多段等未知交互按规则暂不参与排名。缺失数据不视为 0。

## 技术与命令

零第三方运行依赖：原生 ES Modules、HTML、CSS，Node.js 24 内置测试与本地静态服务，Python 3 标准库手动采集。

```bash
npm test
npm run build
npm run dev -- --port 5173
python3 scripts/fetch_data.py
```

`npm run build` 生成 `dist/`，Pages 发布该目录。资源用相对 URL，兼容项目子路径。

## 结构与风格

- `src/`：计算纯函数和 DOM 展示，逻辑/样式分离。
- `public/data/`：规范化快照；`public/assets/`：本地图标精灵。
- `scripts/`：手动采集、构建、静态服务。
- `tests/`：Node 内置单测；`docs/`：中文规格及验证记录。
- `archive/`、`reference/`：原件不改动，排除公开构建。

示例：`minimumHaste(10, 10)` 返回未舍入精度；展示层独立格式化。使用具名函数、显式单位、原生 button/details/input。来自技能说明的 HTML 转纯文本后显示，不注入未经清洗的 HTML。

## 测试策略

- 先写失败测试，再实现公式、并列解、排除规则、精度和搜索。
- 全量数据验证英雄/技能数、资源存在、CD 有限且正值或明确标记缺失。
- 独立验证计算结果的双向不等式，不能只调用同一公式自检。
- 构建只包含站点必需文件，无证书、ZIP、缓存或个人路径。
- 真实浏览器检查搜索、加点切换、并列展开、技能说明、空状态及手机布局。
- 检查 320、768、1024、1440 宽度，无溢出、资源失败和控制台错误。

## 实施顺序与验收

1. 数据：获取锁定版本的中文数据、图标；记录与旧快照的差异和待核验项。
2. 计算：测试通过；最低急速保留精度，整数门槛向上取整，并列不丢失。
3. 页面：深墨蓝金色研究工具；电脑列表/详情，手机单列；真实数据驱动。
4. 发布准备：静态构建和手动 Pages 部署说明；不添加定时更新。
5. 本地验证：完整测试、构建、浏览器交互及截图复核；记录剩余局限。

## 不做与风险

- 不操作游戏客户端，不运行旧参考程序，不使用其证书。
- 不声称基础数据已核实全部模式覆盖；普通技能结果仍为约定模型的理论值。
- 数据缺失、充能近似与特殊技能不能隐藏。
- 正式公开前重新核验 Riot 素材与产品政策。
